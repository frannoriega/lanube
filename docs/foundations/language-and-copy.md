# Foundation: language & copy conventions

- **UI strings are Spanish.** The app is built for a Spanish-speaking
  institution/community — every user-facing label, error message, and
  email template is in Spanish (see `/about`, `RESERVATIONS_CRUD_GUIDE.md`,
  role labels like "Administrador"/"Superadministrador" in `rbac.ts`).
  Code identifiers, comments, and internal docs (this tree included) stay
  in English.
- **Git commit messages are in Spanish**, matching the existing repo
  history and the app's own language (see memory:
  feedback-commit-messages-spanish). This is a standing instruction, not a
  per-commit choice.
- **The Plan Estratégico PDF (`assets/`) is the authoritative source** for
  institutional/public copy (the quadruple-helix framing on `/about`, the
  mission/vision language) — see memory: strategic-plan-source. When
  editing public-facing institutional text, check that PDF before
  inventing new phrasing.
