# Rejected

Negative decisions: things deliberately **not** built (or built and then
reverted), and why. The point of this directory is to stop a future
session — human or agent — from re-proposing something that was already
tried and found wanting, without re-litigating the reasoning from scratch.

Each entry: what was proposed, why it was tempting, why it was said no to.

- [`0001-retroactive-docs-migration.md`](./0001-retroactive-docs-migration.md)
  — why `docs/changes/`, `docs/milestones/`, and `docs/superpowers/` were
  left in place rather than being rewritten into this `docs/design/`
  structure retroactively.

This directory starts thin because the documentation-led workflow itself
is new to this project (introduced 2026-09-21, see
[`docs/design/00-overview.md`](../design/00-overview.md)) — most of the
project's earlier rejected ideas, if any existed, were never written down.
Backfill entries here as they're recalled, rather than treating an empty
history as "nothing was ever rejected."
